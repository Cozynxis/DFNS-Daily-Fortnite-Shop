# 🎮 DFNS — Daily Fortnite Shop

> A modern Fortnite Item Shop browser powered by the Fortnite-API.

DFNS (**Daily Fortnite Shop**) is a modern web application that lets you explore the current Fortnite Item Shop in a clean, fast and responsive interface.

The project uses the public **Fortnite-API** to retrieve Fortnite cosmetic and Item Shop data.

---

## ✨ Features

- 🛍️ Browse the current Fortnite Item Shop
- 🔎 Search cosmetics by name
- 🗂️ Filter items by category
- ↕️ Sort items by name, price and rarity
- ❤️ Add items to your favorites
- 💾 Save favorites locally
- 🔥 Vote for an cosmetic
- 🎨 Rarity-based item styling
- 📱 Responsive design
- ⚡ Client-side caching
- 🔗 Open individual cosmetic pages
- 🪙 Display V-Bucks prices
- 🔄 Refresh shop data from the API
- 🚫 Friendly API error handling

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Page structure |
| CSS3 | Styling & responsive design |
| JavaScript | Application logic |
| Fortnite-API | Fortnite data |
| LocalStorage | Favorites & caching |
